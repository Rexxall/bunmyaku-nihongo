## これは何か

Bunmyaku はローカルで動く Web アプリです。教科書は同梱していません。本文・単語リスト・会話スクリプト・録音を、あなた（または AI エージェント）が **コースパック** というフォルダにまとめると、それが学習机になります。

| 場面 | できること |
| --- | --- |
| 本文精読 | 原文にふりがな、語彙はハイライト、文法は下線。語をタップすると語釈。訳文は必要なときだけ、一文ずつの精読も |
| 語彙 | 語全体の読み、やさしい日本語の語釈、類義語の使い分け、語構成のヒント。自分の言葉で説明を書き、本文の位置へジャンプ |
| 練習 | 穴埋めはその場に答えを表示、選択問題は正解をマーク、書き換えと自由記述。ヒント・答え・解説は別々に切り替え |
| 聴解 | 再生、速度変更、±5 秒、聞き直し、A/B ループと区間の保存。スクリプトと訳文は別々に隠せる |
| 質問 | 語や文を選んで質問。サーバーはその課の校正済みテキストだけをモデルに送る。API キーがなくてもプロンプトをコピーして使える |
| 記録 | ノート・解答・聴解の進み具合は学習者プロフィールごとにブラウザに保存。ひとりなら 1 つ、二人で学ぶなら追加。Markdown に書き出し、語彙は本文の例文と自分の説明つきで Anki へ書き出し |
| 表示言語 | 中国語・日本語・英語。ブラウザの言語に合わせ、右上のメニューで切り替え可能。コースの内容そのものは翻訳しません |

サーバーは Python 標準ライブラリだけのスクリプト 1 本。データベースもアカウントもクラウドもありません。内容は手元のフォルダから、キーは手元に置いたまま、質問はあなた自身の API アカウントで課金されます。

## 3 分で動かす

インストールの前に [オンラインで試す](https://rexxall.github.io/bunmyaku-nihongo/) こともできます。デモ課で精読・語彙・練習・聴解・ノートが使えます。チューターは手元で動かしたときだけ使えます。

Python 3.9 以上。インストールするものはありません。

```sh
git clone https://github.com/Rexxall/bunmyaku-nihongo.git
cd bunmyaku-nihongo
python3 -m bunmyaku --open
```

ブラウザで <http://127.0.0.1:8765/> が開き、オリジナルのデモ 2 課（CC0）が表示されます。コマンドを打ちたくなければ、`bunmyaku.command`（macOS／Linux）または `bunmyaku.bat`（Windows）をダブルクリックしても同じです。スマートフォンから使うには `--bind` にパソコンの LAN アドレスを渡してください。

**チューターをつなぐ**（任意）：

```sh
python3 configure_ai.py
```

プリセットを選びます：任意の OpenAI 互換エンドポイント、DeepSeek、OpenAI、またはローカルの Ollama（キー不要）。設定しなくても使えます。質問パネルが質問と課の資料を 1 本のプロンプトにまとめるので、好きなチャットツールに貼り付けてください。サーバーが送る内容は [チューター・プロトコル](docs/tutor-protocol.md) に書いてあります。

**自分の教材を使う**：

```sh
python3 -m bunmyaku --content ~/my-pack
```

コースパックはフォルダ 1 つ：`pack.json` ＋ `lessons/*.json` ＋ 任意の `media/`。項目は [コースパック形式](docs/pack-format.md) に、完全な例は `examples/demo-pack/` にあります。

## エージェントにコースパックを作らせる

パック形式は、人が読み、エージェントが書くために作ってあります。リポジトリには `.claude/skills/make-course-pack/` スキルと `AGENTS.md` が入っています。Claude Code や Codex などに「この課をコースパックにして」と言えば、決まった手順で進めます：まず教材を全部読む、段落と文に分ける、語彙は本文からだけ取る、訳文は機械訳か人の校正かを明記する、読みを一語ずつ確認する、バリデータを通す、最後に「人が確認すべき項目」の一覧を出す。例文の出典をでっち上げること、未確認の読みを確認済みにすることは禁止です。

ローカルで動くツールが 2 つあります：

```sh
python3 tools/validate_pack.py my-pack          # 構造、参照、ふりがなの網羅率、練習の答え
python3 tools/import_text.py --text lesson.txt --vocab words.csv --out my-pack --id my-pack   # テキスト → 最小のパック
```

単語リストには Anki のデッキもそのまま使えます。「Notes in Plain Text」（.txt）か、「Support older Anki versions」を付けた .apkg で書き出し、`--map word=1,reading=2,meaning=3` でどの列が何かを指定します。Anki 式のふりがな `日本[にほん]語[ご]` は語と読みに分けられます。

## データとプライバシー

- 学習記録は今使っているブラウザに、パック・課・プロフィールごとに保存されます。書き出さない限り端末間で同期しません。
- サーバーが出すのはページ、API、パックが参照する音声だけ。パックのファイルやリポジトリのファイルは公開されません。
- チューターに送るのは送信時の質問、選択したテキスト、その課の校正済みテキスト、直近のやり取りだけ。音声・ノート・キーは送りません。
- 著作権のある教科書や私的なパックはリポジトリの外に置き、`--content` で指定してください。コミットしないでください。

## 構成

```text
bunmyaku/           python3 -m bunmyaku の入口とバージョン
serve.py            ローカル HTTP サーバーとチューター中継
packlib.py          コースパックの読み込み
manage.py           スナップショット、検査、公開、ロールバック
configure_ai.py     チューター接続の設定
src/                ページの骨組み、動作、スタイル
tools/              パックのバリデータ、インポータ、静的書き出し
examples/demo-pack  オリジナルのデモパック（CC0）
docs/               形式、プロトコル、配置、設計メモ
test_*              サーバー、リリース、ツール、ブラウザのテスト
```
